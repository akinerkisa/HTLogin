# Contributing

1. Create a focused branch from `main`.
2. Install development dependencies with `pip install -r requirements-dev.txt`.
3. Run `pytest` and `ruff check .` before opening a pull request.
4. Add or update tests for behavior changes.
5. Keep payloads non-destructive and document any new network behavior.

Pull requests should explain the security rationale, expected false-positive
behavior, and how the change was tested.
